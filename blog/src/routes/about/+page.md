## 書いている人

techcurrypan。仕事で触った技術と、個人で作った物について書いています。

調べたことをそのまま置いておくと、同じ所で止まった人の役に立つことがあるので、つまずいた箇所も消さずに残しています。

## このサイトの作り

- SvelteKit（Svelte 5 + Vite + TypeScript）
- mdsvex で Markdown を記事に
- Cloudflare Workers で配信
- GitHub Actions で、push したら検査して自動公開

作った手順は「ブログを作る」の連載にまとめています。
