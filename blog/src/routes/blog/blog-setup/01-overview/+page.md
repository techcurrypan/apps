技術ブログを一から作った記録を、再現できる形で残す。同じ手順をたどれば、同じものができる。

## 作るもの

- Markdown で記事を書く
- 記事を 1 本足すと、一覧とタグに自動で載る
- `git push` すると自動で検査され、公開される
- 費用はゼロ

## 使う道具

| 道具 | 役割 |
|---|---|
| Node.js | 手元で動かすための土台 |
| SvelteKit | サイトを組み立てる枠組み |
| mdsvex | Markdown をページにする |
| GitHub | コードの置き場と、自動化の実行場所 |
| Cloudflare Workers | 公開先 |

全て無料で、クレジットカードの登録も要らない。

## 全体の流れ

```
手元で書く
  ↓
git push
  ↓
GitHub Actions が検査（型・書式・組み立て）
  ↓
通ったら Cloudflare へ配信
  ↓
公開 URL で見える
```

検査を挟んでいるのが大事なところ。壊れたものは公開されない。

## 必要な前提

- パソコン（Windows で確認。Mac でもほぼ同じ）
- GitHub のアカウント
- Cloudflare のアカウント（この連載で作る）

プログラムの経験は、あった方が楽だが必須ではない。コマンドをそのまま打てば進む。
