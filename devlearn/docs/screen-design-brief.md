# 画面設計の依頼書

devlearn の画面は**この文書に沿って、画面設計の段で一から設計する。** ここでは決めない。

参考サイト（Protocol Explorer）の配置・配色・絵・文言を写さない。
取り入れるのは `reference-analysis.md` の**原理 1〜8** だけ。

設計の結果は `docs/screen-design.md` に書き、`docs/decisions.md` に決着として残す。

---

## 1. 入力

画面設計の段に入る前に、次が終わっていること。

- `docs/curriculum.md`（何を教えるか）
- `docs/game-design.md`（何で遊ぶか）

画面は、この 2 つを**同じ場所で**成り立たせるためにある。
説明だけの画面、ゲームだけの画面を別々に考えない。

## 2. 満たすべきこと

| ID | 内容 |
|---|---|
| D-1〜D-8 | `reference-analysis.md` の原理 1〜8 を全て満たす |
| D-9 | `explanation-standard.md` の型（図の変化・説明と具体値・記録）を、どれも欠けずに見せられる |
| D-10 | 実戦（道具の操作）・間違えたときの返事・ゲームの手、の 3 つが、説明と同じ画面体系に収まる |
| D-11 | 学習の場面とゲームの場面の行き来が、迷わずできる |

| D-16 | 日本語のみ |
| D-17 | **今のステップの動きを、留まったまま繰り返し再生できる**操作がある |
| D-18 | 変化の前 → 動き → 後の状態が見える |

## 3. 決めること

1. **画面の種類** — いくつの画面があり、それぞれ何のためか
2. **説明の画面の構成** — 図・説明・記録をどこに置くか。いくつの表し方を同時に
   見せるか（原理 4）。それはなぜか
3. **図の見方** — 1 つの出来事をいくつの見方で表すか。見方は題材によって
   変えるか
4. **位置の示し方** — レッスン内・分野内・ゲーム内の位置をどう見せるか（原理 5）
5. **操作** — 進む・戻る・飛ぶ・自動・速さを、どこに、どう置くか（原理 6）
6. **実戦の置き場** — 道具の操作を説明と同じ画面でするか、切り替えるか
7. **ゲームとの同居** — ゲームの状態を常時見せるか、必要なときだけ出すか
8. **見た目の土台** — 色・文字・余白・角丸・動きの速さ（第 4 章）
9. **携帯での形** — 狭い幅でどう畳むか

## 4. 見た目の土台の候補

見た目の土台（色・文字の大きさ・余白・角丸・アクセシビリティの基準）を
一から作るか、既存の公開物を土台にするかも、ここで決める。

| 候補 | 中身 | 条件 |
|---|---|---|
| 一から作る | 色・文字・余白を自分で決める | — |
| **Astryx**（`github.com/meta/astryx`） | Meta のデザインシステム。MIT。テーマは CSS 変数 | 下の確認を全て行う |

Astryx を候補にするときの確認

- ライセンス文（LICENSE）を読み、表示義務を守る。`docs/third-party.md` に記録する
- **部品は使わない**（React 専用。devlearn は Svelte）。使うのはトークン
  （CSS 変数）・基礎（文字・色・配置・アクセシビリティの基準）・パターンの考え方
- **React 無しで CSS が読み込めるか**を実際に確かめる
- 暗い配色のテーマがあるか確かめる。無ければ自分で作る方法を決める
- ベータ版なので**版を固定する**。更新は自分で判断して行う
- 確認日と出典を記録する

## 5. 決め方

- 案を **3 つ**作る。うち 1 つは Astryx を土台にする案とする
- 各案を 1 ページで書き、第 3 章の 1〜9 を埋め、**簡単な構成図**を付ける
- 各案について D-1〜D-18 を満たすかを表で判定する
- **選んだ理由と、落とした案を落とした理由**を書く
- 選んだ案を `docs/screen-design.md` に詳細化する

## 6. 詳細化で書くこと

- 画面ごとの構成図と、各領域の役割
- 状態と画面の対応（どの状態のとき、何が見えるか）
- 色・文字・余白・角丸・動きの速さの値（CSS 変数の一覧）
- キーボード操作の一覧
- 携帯幅での形
- 原理 1〜8 をどこで満たしているかの対応表

## 7. やらないこと

- 参考サイトの配置・配色の値・絵・文言・題字の複製
- Astryx の部品の移植
- 多言語対応
