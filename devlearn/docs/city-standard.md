# 街の見た目とゲーム性の水準

D-14 の具体の基準。**全項目を満たすまで段 8 を終えない。**
手本は試作 `docs/prototype/minato.html`（利用者が「この方向で良い」と認めた物）。実装はこれと同等以上にする。

利用者が退けた物：四角を並べただけの図、札と数値の帯だけの画面、ゲームの手応え（時間・お金・人・建てる・出来事）が無い画面。

---

## 1. 絵（描画）

全てプログラムで作る自作の 3D（WebGL2）。外部の 3D 素材・画像・ライブラリの模型を持ち込まない。

| ID | 項目 | 確かめ方 |
|---|---|---|
| V-1 | 斜め上から見下ろす立体の街。カメラは移動・回転・傾き・ズームが滑らか（減速つき） | 操作して撮る |
| V-2 | 太陽の光と影（影の地図）。影は建物・木・車から落ちる | 昼の撮影で影がある |
| V-3 | 隅の陰り（画面空間の遮蔽など）。建物の足元・壁の隅が暗くなる | 近くで撮る |
| V-4 | 空と霧。遠くの丘が霞む。雲が流れ、雲の影が地面を動く | 遠景で撮る |
| V-5 | 時刻で光が変わる：朝・昼・夕焼け・夜。夜は窓がともり、街灯の光だまりが落ち、明るい物がにじむ | 4 時刻で撮る |
| V-6 | 水：波で揺れ、空と日差しを映し、浅瀬は色が変わり、岸に白い泡 | 港で撮る |
| V-7 | 建物の種類：一戸建て（切妻・寄棟・瓦の段）、マンション（バルコニー）、オフィス（帯窓・全面ガラス・低層と高層の組み合わせ）、商店（日よけ・看板・縦看板）、役場（時計塔・柱廊）、学校（校庭のトラック・体育館・プール）、診療所、倉庫、神社、灯台 | 種類ごとに撮る |
| V-8 | 建物の細部：窓の枠、屋上の設備、手すり、基礎、玄関のひさし、室外機。夜の窓の明かりは窓ごとに決まり、ちらつかない | 近くで撮る |
| V-9 | 道：車線と中央線、横断歩道、停止線、歩道の縁石、信号、街灯、電柱と電線、バス停 | 交差点で撮る |
| V-10 | 自然：丘の森（広葉樹・針葉樹、季節の色）、畑、浜、島。地面は色むらと細かい模様があり、一色に塗らない | 遠景で撮る |
| V-11 | 港：岸壁、ガントリークレーン、積み上げたコンテナ、停泊した船、桟橋、防波堤 | 港で撮る |
| V-12 | 選んだ建物・押せる建物が光って分かる | 押して撮る |
| V-13 | 遠近の効き：近くを見ると画面の上下がぼける（ミニチュアの見え方）。遠くを見るときは弱める | 近景と遠景を比べる |

## 2. 街の動き（見た目だけ。状態を変えない）

| ID | 項目 |
|---|---|
| L-1 | 車・バス・トラックが車線を走る（日本の左側通行）。交差点で曲がり、信号の赤で止まり、前の車に詰めて並ぶ |
| L-2 | 人が歩道を歩く |
| L-3 | 船が海を行き来する。旗がはためく |
| L-4 | 一時停止すると全ての動きが止まる。速さ 1〜3 で動きが速くなる |
| L-5 | 見た目の動きは種つきの擬似乱数と描画の時刻で動かしてよい。**状態（人口・資金・満足度・要望）を決める処理には使わない** |

## 3. ゲーム性

| ID | 項目 |
|---|---|
| G-1 | 時間が進む：日付と時刻、一時停止と速さ 3 段（キーボードの Space と 1〜3 でも） |
| G-2 | 常に見える数：人口、資金と 1 時間あたりの収支、満足度（色つきの棒）、需要（住・商・職）。資金を押すと、収支の内訳（何が・いくつ）と最近の出入りが出る（要件の B-3） |
| G-3 | 要望が届くと知らせが出て、依頼主の建物の上に印（!）が立つ。印と一覧のどちらからでも開ける |
| G-4 | 要望の板：依頼主・言葉・条件・見返り・期限、効く解説への道、学んだ手（学んでいないと選べず、理由を出す）、学ばずに選べる手、後回し |
| G-5 | 応えると、カメラがその場所へ動き、建物が足場と砂ぼこりの中から建ち上がり、周りの建物に満足の印が浮く。結果の知らせに「変化をもう一度」と「地下の仕組みで見る」 |
| G-6 | 地下の仕組みの表示：建物を暗くし、通信・記録などの流れが地面を光って流れる。混んでいる所は赤く脈打ち、直すと色が変わる |
| G-7 | 満足度の表示：建物を満足度で塗り分ける |
| G-8 | 街づくりの道具：住宅地・商業地は空き区画を**指定**し、需要に応じて時間をかけて建物が建っていく（種と時刻から決まる。乱数を使わない）。公園はその場で作る。取り壊し（自分で建てた物）。費用が足りないと理由を出す |
| G-8b | 道路：街の端の交差点から外へ、引く前に緑（引ける）／赤（引けない理由つき）で形と費用を見せる。引くと沿いに空き区画ができ、車がその道を通る |
| G-9 | 建物を押すと、名前・住む人・働く場所・満足度・その建物の人の声 |
| G-10 | 前に学んで建てた仕組みが、後の要望で使い回せる（例：記録庫に商店街の帳面をつなぐ） |
| G-10b | 分野ごとに違う「仕組みの建物」が建つ（試作では git → 記録庫、db → 帳簿の倉庫、sec → 門番の小屋）。地下の仕組みの表示で、分野ごとに色の違う流れになる |
| G-11 | 期限を過ぎると近くの満足度が下がる |
| G-12 | 初めて開いたときに、遊び方を 3 行で示す |

## 5. 重さ

| ID | 上限・決まり |
|---|---|
| P-1 | 動かない物の三角形 90 万以下。1 枚を描く呼び出し 40 回以下 |
| P-2 | 描画の解像度を自動で下げる（重いときは 0.55 倍まで）。端末の画素比は 1.75 まで |
| P-3 | 動く物（車・人・船）の形は毎回作り直すが、入れ物を使い回し、毎回の確保をしない |
| P-4 | WebGL2 が無い端末では、その旨を出し、要望の一覧と解き方の板で遊べる（要件の T-7） |
| P-5 | 手元の Chrome（利用者の PC）で、1280×720・既定のカメラ・昼・速さ 1 のとき、10 秒の平均で 1 コマ 33 ms 以下（30 コマ/秒以上）。満たさないときは、影の地図の大きさ・隅の陰りの点の数・木の形の細かさを、見た目が試作より落ちない範囲で下げる |
| P-6 | 読み込みから街が見えるまで、手元の Chrome で 5 秒以内。その間は「街を描いています」と出す |

## 6. 確かめ方

- 撮影は `scripts/look.ts`（手元の Chrome）で行う。本番の `/town` にも、試作と同じ撮影の口を作る：
  URL の末尾が `#still` のときだけ描画の繰り返しを止め、`window.__game`（`cam.v` で視点を置く・`S.minute` で時刻を置く・`setView` で表示を切り替える）、
  `window.__snap()`（視点をすぐ合わせる）、`window.__frame(n, dt)`（n コマ進める）を出す。`#still` でないときは出さない
- 試作は `file:///…/docs/prototype/minato.html#still` で開く。同じ口があるので、同じ式で同じ角度・時刻にできる
- 撮る 5 枚（`cam.v` は `{ tx, tz, yaw, pitch, dist }`、`S.minute` は 0 時からの分）：

| 名前 | 視点 | 時刻 | 表示 | 見る物 |
|---|---|---|---|---|
| 全景 | `{ tx: 20, tz: -20, yaw: 0.75, pitch: 0.5, dist: 300 }` | 960（16:00） | 地上 | 街の広がり・建物の種類・影・霧 |
| 広場 | `{ tx: 30, tz: -30, yaw: 0.9, pitch: 0.42, dist: 130 }` | 960 | 地上 | 役場・広場・木・車・信号・隅の陰り |
| 港 | `{ tx: 150, tz: 185, yaw: 2.4, pitch: 0.35, dist: 130 }` | 1000（16:40） | 地上 | クレーン・コンテナ・船・水の反射 |
| 夜 | `{ tx: 20, tz: 0, yaw: 0.6, pitch: 0.42, dist: 380 }` | 1230（20:30） | 地上 | 窓の明かり・街灯・看板のにじみ |
| 地下 | `{ tx: 0, tz: 60, yaw: 0.4, pitch: 0.8, dist: 420 }` | 960 | 地下の仕組み | 流れ・混雑の脈・暗くした建物 |
