## 作った物

- `src/lib/lesson/types.ts`：`explanation-standard.md` 第 2 章の型をそのまま写した
- `src/lib/lesson/check.ts`：第 3 章の 15 項目。`checkLesson(lesson, 既知の ID)` と
  `checkAll(lessons)`（ID の重複も落とす）。落ちた所を「レッスン / 検査の番号 / 場所 / 理由」で返す
  - 字数は見た目の 1 字を 1 と数える（`Intl.Segmenter` の書記素）
  - 文は全角の `。！？` で切る。括弧の中の句点と、コードに出る半角の `?` `!` では切らない
  - 禁止語は「ご存知の通り」などの表記の揺れを寄せてから探す。レッスンの全ての文字列が対象
  - 検査 10 は、ステップの順・ステップ内の順に、出ている物の集まりを追う。出ている物の
    2 度目の `appear`、消えた物の利用も落とす
- `src/lib/lesson/state.ts`：`stateAt(lesson, n)`。ステップ n の
  本文 / 具体値 / 図（前の図・動き・後の図）/ 記録（1〜n 行）/ 進み（済・今・先。先の題は見せない）
  を返す。全てが同じ `n` を持つ。毎回 1 から作り直すので、呼ぶ順に依らない。
  `change` の動きは変わる前と後の値を、`vanish` の動きは消える物の名前を持つ。
  動きを持つので、画面は前の図から後の図への動きを何度でも再生し直せる
- `src/lib/content/lessons/git-001.ts`：見本「add と commit で記録を積む」（7 ステップ）。
  ID・件数・エラー文は全て、git 2.54.0 を手元で書いた人と日時を固定して実際に打って得た物
  （ファイルの先頭に条件を書いた）
- `src/lib/content/lessons.ts`：全レッスンの一覧
- `scripts/content-check.ts` + `scripts/lib/content-report.ts`：一覧を検査し、落ちたら 1 で終わる。
  レッスンが 0 本でも落とす（一覧の読み込みが壊れたことに気付くため）

  見本では `at` を「列・行の目安」として置いた。どう使うか（使わないか）は段 5 で決める
- `Practice.setup` / `success` は `unknown`。見本は git の模擬が読む形を仮に置いた。
  形は段 7 で道具を作るときに決める
- 見本の ID `git-001` は仮。段 3 の ID の付け方と合わなければ付け直す
