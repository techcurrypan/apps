### 黒い四角の原因と直し方

- 頭無しの Chrome（GPU）で、試作でも本番でも、昼の全景にも出ていた。四角の真ん中に 1 点の明るい点があり、1 点の数でない値（NaN）か無限大が、1/4 の大きさでぼかすにじみで四角に広がっていた
- にじみの入力を拾う所で、`isnan` で除いても消えなかった（端末の組み立てで `isnan` が消される）。浮動小数の指数の桁（`floatBitsToUint`）で数でない値を見分けて 0 にし、明るさを 64 までにした。5 枚の全てで本番から消えた（試作には残る）
- あわせて、長さ 0 の法線の `normalize`・負の色の `pow`・地下の線の長さ 0 の区間を避けた
