使い捨ての Python（リポジトリには入れていない）で `curriculum.md` と `game-design.md` の表を読んだ。

| 確かめた物 | 結果 |
|---|---|
| 段 3 の 163 本の全てに手があるか / 手の無いレッスン・レッスンの無い手 | 163 本全てに 1 つずつ。どちらも 0 |
| 手と症状が指す原因が全て第 9.1 章にあるか | 欠け 0 |
| どの症状にも入らない原因 / どの手にも出ない原因 | どちらも 0（156 個全て） |
| 学んだ手で調べられない原因 | 0。直す手が無い 5 個（c-brute・c-cilog・c-phish・c-refused・c-status）は、手探りで直す |
| 症状の原因の数が 4〜7 か | 34 個全て |
| 疑いの平均 | 0.79（7.4 の見積もりに使用） |

さらに、文書の規則どおりに動く模擬で、4 章 × 種 5 つを「学ばない / 半分修了 / 全て修了」の 3 通りで流した（7.4 の表）。
学ばない遊び方は 20 通り全てで合格（信頼 68〜79）。半分は 80〜99、全ては 100。
この模擬で、最初の文書に「週の終わりに受付中の依頼をどう数えるか」が無いことに気付き、11 章に足した。
机上の見積もり（約 63）が模擬（68〜79）と食い違ったので、7.4 を模擬の結果に書き直した。
