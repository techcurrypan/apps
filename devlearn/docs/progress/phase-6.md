# 段 6　画面と再生装置

状態: **完了**（2026-11-10）

## 作った物

- 再生装置（`src/lib/player/`）。どれも純粋な関数で、単体テストつき
  - `timeline.ts`：経過時間と速さから、再生の段階（前 / 動き k の途中 t / 後）を返す
  - `frame.ts`：ステップの図（`stateAt(n).scene` の前・動き・後）と段階だけから、舞台の絵を作る。
    `layoutOf(lesson, mode)` はレッスン全体で大きさを 1 つに決める（ステップが替わっても図が跳ねない）。
    狭い幅（`narrow`）では格子を細くし、物の値を「名前」と「値」の 2 行に分ける。`fitText` は日本語の字を広く数えて切り詰める
  - `control.ts`：前へ・次へ・飛ぶ・最初・最後・もう一度・自動・速さを、状態 → 状態の関数で
  - `keys.ts`：`screen-design.md` 6 章のキー割り当て
  - `kinds.ts`：出来事の種類を、レッスンで初めて出た順に色の枠 1〜5 に当てる
- 画面（`src/lib/ui/`、`src/routes/`）
  - 枠（`+layout.svelte`）：上に devlearn・地図・配色（明 / 暗 / 端末に従う、`T`）・キーの表（`?`）、下に配信のコミット ID と組み立て日時・ライセンスの一覧
  - 入口 `/`、地図 `/map`（11 分野。書かれたレッスンへの道。ロック無し）
  - レッスン `/lesson/<id>`：帯（位置・段・進み）/ 舞台 / 操作帯 / 台本 の 4 領域。7 段は札で切り替え（`Shift`+矢印）
  - 舞台 `Stage.svelte`（SVG）：前の図 → 動き 1 つずつ → 後の図。下に「前 → 動き k/m → 後」と記録の最新 1 行
  - 台本 `ScriptPanel.svelte`：文（題・要約・本文・なぜ）→ 具体値 → 記録（1〜n 行、n 行目に ▶）
  - 操作帯 `Controls.svelte`：前へ・もう一度・次へ・自動・速さ。狭い幅では画面の下に固定し、自動と速さは「…」の中
- 見た目：Astryx theme-neutral 0.7.11 の `theme.css` を `static/vendor/` に写した（先頭にライセンスの全文。注記の後ろの SHA-256 が記録と同じことをテストで確かめる）。
  `src/app.css` に `--dl-*` の変数（`screen-design.md` 4 章）。配信物に `third-party-licenses.txt`
- `scripts/look.ts`：手元の Chrome を DevTools の口で動かし、URL を**キーだけで**操作して確かめ、画面を撮る（CI では走らせない）

## 設計からの直し（`screen-design.md` に書き足した）

| 何を | なぜ |
|---|---|
| 狭い幅の舞台：格子の幅 150・値を 2 行 | 広い幅の図をそのまま縮めると、携帯で値の字が約 6px になり読めない。列と行を入れ替える形も試したが、舞台が約 430px の高さになり、5 章の「縦 640px に舞台・記録の最新・文」を満たせなかった |
| `--dl-stage-min` は 2 列の幅だけ | 狭い幅で空白を作り、記録の最新行を 640px の外へ押し出していた |
| 記録の最新 1 行を広い幅でも舞台の下に出す | 1280×800 で、記録が台本（文・具体値）の下に押し出され、舞台・文と同時に見えなかった（原理 4） |
| 狭い幅の操作帯を `position: fixed` に | `sticky` では左の列の中でしか留まらず、文まで下ると操作帯が消えた（5 章「下に固定」） |
