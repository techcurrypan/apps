## 試作の形（本番の手本）

**合否の基準は `docs/learn-standard.md`**（全項目で試作と同等以上。LS-* と比べる場面 C-*）。配置の説明は `screen-design.md` 第 11 章。要点だけ：

1. 上の帯：分野・詳しさ（はじめて / 現場 / 中身まで）・資金と支持率・手帳
2. レッスンの帯：題・「この学びで育つ物」の箱（押すと街へ）・見る / やってみる / 思い出す
3. 左：章と出来事の番号（済んだ物だけ押せる。押すとその時点へ戻る）
4. 中：図（機械と向き付きの線。名札に町での呼び名）→ 一行の説明 → 時間の帯（戻る・次へ・自動・速さ・番号の点）
5. 中の下：**中身の板**＝荷物の中身（層の帯・欄・16 進）｜OS の中（プロセス・つながり・ファイル）｜ログ（新しい行が上）
6. 右：今の出来事の説明・この章の値・変わったこと（前 → 後）・町では・仕事では。実戦では端末・要望・命令の見本・**コマンドの参考（公式の説明だけ）**
7. 下：あなたの操作の記録（番号・時間・送り元・宛先・種類・内容・大きさ）

## 本番に移すときに直す物

- 書体：試作は Google Fonts を読む。本番は外の書体を読まず `--dl-font` を使う（`screen-design.md` 4.3）
- 色：試作の値ではなく `--dl-*` のトークン（明暗の両方）。試作は分野ごとに色を付けているが、D-12「分野に色を塗らない」に合わせ、
  色は出来事の種類と 4 つの状態（今・済・誤り・注意）だけにする
- 中身：試作のレッスン 4 本（net・git・k8s・ai）は試作の中に直に書いた物。本番はレッスンのデータ（`explanation-standard.md` 第 2 章）から描く。
  中身の板の材料は `Step.inside`（`explanation-standard.md` 2.1）
- 「この学びで育つ区画」の★は試作の仮。本番は `game-design.md` 第 8 章の「このレッスンで増える街の手」と、効く要望を出す
- 試作の 3D の町（`town3d.js` 相当）は学習画面では使わない。街は `/town`（D-14・D-15）
- 左上の印・試作用の `window.__l` `window.__beats` は外す
