# 街の試作（みなと町）

2026-11-10 に、利用者の指示「Cities: Skylines II やサカつくのような、まともなグラフィックとデザインとゲーム性」を受けて、
この会話で**一から**作った試作。利用者が「この方向で良い」と認めた（D-14）。旧実装ではない。

- `minato.html` … 1 枚で動く試作。ブラウザで開くと遊べる（Google Fonts の読み込みだけ外に出る）
- `src/engine.js` … 自作の WebGL2 の描画（影の地図・隅の陰り・にじみ・ミニチュアのぼけ・霧・空・水・夜の窓）
- `src/gen.js` … 街の形をプログラムで作る（地形・道・区画・建物の種類・木・港・電柱・信号）
- `src/game.js` … 時刻と光、車・人・船、要望と解説、建てる道具、地下の仕組みの表示、操作
- `src/index.html` … 重ねる板の見た目と配置

## 使い方

- 段 8 は、この試作の**コードを土台にする**（D-16）。一から書き直さない。手順は `docs/plan.md` 8-2a〜8-2f
- このフォルダの物は比べる相手なので、消さない・書き換えない
- 移すときに `CLAUDE.md` の規則に合わせ直す物：
  - 状態（人口・資金・満足度・要望）を決める処理を、描画から切り離した純粋な関数にする（試作は 1 つに混ざっている）
  - 試作の要望の解き方は簡略版。本番は `game-design.md` 第 4〜7 章（候補 4 つ・調べる・示す・直す・いつでもの手）にする
  - 試作の解説は簡略版。本番はレッスン画面の再生装置（段 6）を使う
  - 試作の数値（費用・収入・人口・目標）は仮。根拠のある数は段 8-1 で決める
  - 試作は建物の色や区画に建つ物を `R()`（種つきの擬似乱数を呼んだ順に引く）で決めている。呼ぶ順が変わると結果が変わるので、
    状態に入る物は「種と区画の番号と時刻」から決める式に直す（`gen.js` の `hash2` のような形）
  - 試作の時刻は実時間で進む（`S.minute += dt * …`）。本番は「ゲーム内の分」で刻んで進め、描画は状態を読むだけにする（`game-design-brief.md` 第 6 章 1）
  - 試作は Google Fonts を読む。本番は外の書体を読まず `--dl-font` を使う（`screen-design.md` 4.3）
  - 板の色は試作の値ではなく `--dl-*` のトークン（明暗の両方）を使う。3D の街の中の色は試作のまま
  - 左上の「途中版」の印は外す
- `#still` を付けて開くと描画が止まり、`__frame(n, dt)` で進められる。`window.__game` で視点と時刻を置ける（撮影用。`city-standard.md` 第 6 章）
