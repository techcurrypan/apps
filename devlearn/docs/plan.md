## 段 11　MCP サーバ

外の AI がレッスンを読めるようにする。**読み取りだけ。**

**作る物**

- 同じ Worker の道 `/mcp` に MCP サーバを置く。通信の形は MCP の公式仕様の Streamable HTTP（作る日の最新の版を読み、版と確認日を `docs/third-party.md` か `free-services.md` に書く）
- 道具（tools）：`list_lessons`（分野で絞れる。ID・題・分野・難易度・到達目標）、`get_lesson`（ID で 1 本の全文）、`get_graph`（推奨前提・関連・次に学ぶとよい）。
  **D-25**：`get_terms`（分野の言葉の一覧）、`get_rubric`（原稿の採点表 R1〜R12 と、各項目の手本の 4 点と 2 点の例。`mastery-standard.md` 第 5 章）。学ぶ人の AI が査読の依頼票（第 6.2）を読む時に使う。**原稿は受け取らない・保存しない**
  書き込む道具は作らない

- 認証は付けない（読み取りだけで、利用者のデータを持たないため）。利用者の保存データ（修了の記録・街の保存）はブラウザの中だけにあり、Worker は持たない
- 公式の SDK を使うなら、ライセンスを確かめて `third-party.md` に書く。Workers で動かないなら、仕様どおりの JSON-RPC を自分で書く
